## 概览

该项目由 Agent 服务端和跨平台客户端组成，面向电厂知识查询、数据库检索和分析报告生成等场景。工作内容覆盖 Agent 能力组织、业务接口、客户端交互以及服务部署与联调。

## Agent 服务端

服务端将知识文档、业务数据和数据库接入统一的问答流程，并提供多轮对话和报告生成能力。

主要工作包括：

- 建设问答服务和会话管理能力，根据问题类型选择知识检索或业务数据查询。
- 组织知识库索引与混合检索流程，提高专业文档和设备信息的召回能力。
- 对不同数据源的查询结果进行统一整理，使 Agent 能够组合知识与现场数据回答问题。
- 实现异步报告任务，支持任务状态、分析依据、结果产物以及取消和重试。
- 完成环境配置、容器化部署和服务运行维护，并通过测试持续检查主要业务链路。

## 跨平台客户端

客户端为问答、报告和语音交互提供统一入口，并适配桌面端、移动端和 Web 端的使用场景。

主要工作包括：

- 实现多轮对话、会话历史和 Markdown 内容展示。
- 建设报告工作区，支持创建任务、查看进度与结果，以及取消和重试任务。
- 接入语音转文字与语音播放服务，补充文字之外的交互方式。
- 将 Agent、语音识别和语音合成服务分别配置，统一处理连接状态、异常提示和本地设置。
- 按功能划分数据模型、服务调用、状态管理和界面组件，保持多端功能的一致性。

## 项目边界

系统定位为面向专业场景的知识查询与分析辅助工具，不直接参与生产设备控制，也不替代人工运行决策。回答和报告结果仍受知识内容、数据质量及模型能力影响，因此设计中强调来源依据、过程记录和结果可追溯性。
