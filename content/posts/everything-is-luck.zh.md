## 什么是运气？

我一直有个问题，多少是运气？首先，如下两类事情算是运气：

- 未经本人选择的条件：出生、家庭，以及早期受到的影响。我们可以追问：多早叫早期？如何界定第一个本人选择，而不是环境+随机事件导致？
- 不由本人掌控的随机事件：例如某次偶遇。随机不等于无法预测概率；例如掷骰子可以预测各点数的概率，但本人并不能因此掌控结果。

这两类事情不必互斥，但“未经选择”和“随机”并不是同一个意思。一个条件即使完全确定，只要不是我选择的，例如我的出生背景，对我而言仍然属于这里说的运气。因此，本文所说的“运气”包括：未经本人选择的初始条件、不由本人自主决定的外部遭遇，以及不由本人掌控的随机因素。论证的关键不在于世界是否随机，而在于我是否最终选择了塑造自己的条件。

出生背景和先天条件带来的优势，通常就可以归为对本人而言的运气；用生物过程或自然规律解释其成因，并不会把这些优势变成本人选择或努力的成果。本文从这些条件出发，追溯后来选择和努力的形成。**结论覆盖到全部行为，并不要求扩大“运气”的定义。**

**本文要论证的是：一个人的任何行为，最终都完全取决于对他而言的运气。** 这里讨论行为对其来源的依赖关系，无须把行为本身也归类为运气。“完全取决于”包含实际参与过程的随机因素，不要求仅凭初始状态就能唯一预测未来。

这里也区分两种“随机”：一种是变量太多、信息不足，导致我们无法预测结果；另一种是即使完整的先前状态和规律相同，也可能出现不同结果。下面的论证兼容这两种情况：前者仍可追溯其形成条件，后者的具体结果同样不由本人掌控，属于这里所说的运气。

## 我的问题与思考

很多人说天赋很重要；有的人说：不，努力很重要；有的人说：不，选择很重要；当然有人也会说，运气也很重要。

但我觉得，这一切不是取决于运气吗？比如，一个小孩儿出生，它的基因、家庭背景、地区和国家是运气吗？它的选择是主观能动性吗？它的选择重要吗？举个例子：比如他选择第一次抬手，抬左手还是抬右手，抬了多少度？这个叫随机事件还是叫选择还是叫努力，和他的基因、家庭背景、地区和国家相比，决定它未来的人生的比例各占多少？

天赋所带来的优势可以归于运气。如果婴儿时期的状态与动作都来自未经本人选择的条件，那后来出现的选择和努力从什么时候开始具有独立于这些条件的来源？难道是6岁开始的？还是5岁开始的？还是12岁开始的？

那么，那一次的选择或者努力，即使被称为“主观能动性”，为什么就能获得一个独立于此前形成条件的来源呢？从受精卵开始，先前状态在自然规律下演化，并受到外部条件及可能的随机因素影响；把后来某一步称为选择或努力，需要继续解释这一步是怎样产生的。

## 论证过程

### 1. 数学符号

先考虑内部状态和行为均采用离散表示的情况，用向量表示内部状态、外界条件和行为：

| 符号              | 含义                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| $t$               | 时间下标                                                                                                  |
| $\mathbf S_t$     | 时刻 $t$ 的内部状态向量，包括既往经历在本人身上保留的、影响当前行为的信息，如记忆、知识、技能、习惯和动机 |
| $\mathbf E_t$     | 时刻 $t$ 的相关外界条件向量，包括既往事件延续至今的外部影响，如支持关系、资源和机会                       |
| $\mathbf A_t$     | 时刻 $t$ 的行为随机向量，包括选择和努力                                                                   |
| $\mathbf a$       | 行为向量的一个具体可能取值                                                                                |
| $p_t$             | 时刻 $t$ 的行为条件概率质量函数                                                                           |
| $\mathbf S_{t+1}$ | 下一时刻的内部状态随机向量                                                                                |
| $\mathbf s'$      | 下一时刻内部状态的一个具体可能取值，撇号不是求导符号                                                      |
| $q_t$             | 从时刻 $t$ 到 $t+1$ 的内部状态转移条件概率质量函数                                                        |

这里约定，$\mathbf S_t$ 和 $\mathbf E_t$ 共同包含历史中与当前行为生成有关的全部信息。历史影响按其当前存在的位置归入内部状态或外界条件，不再单独引入历史变量。例如，早期鼓励留下的信心和技能计入 $\mathbf S_t$，延续至今的支持关系计入 $\mathbf E_t$。

### 2. 行为函数

给定内部状态和外界条件，行为取值为 $\mathbf a$ 的概率写成：

$$
\boxed{
\Pr(\mathbf A_t=\mathbf a\mid\mathbf S_t,\mathbf E_t)
=p_t(\mathbf a\mid\mathbf S_t,\mathbf E_t)
}
$$

其中，$\mid$ 表示“在给定这些条件的情况下”；$p_t$ 的下标 $t$ 表示时间，不是乘法。对每一组给定的状态和条件，各可能行为的概率非负，且总和为 $1$。

这个表示也包含确定性行为：如果某个行为 $\mathbf a^\ast$ 的条件概率为 $1$，其他行为的条件概率均为 $0$，就得到全部概率集中于一个结果的退化分布。因此，使用概率表示不要求每一步都具有非确定性。

### 3. 行为动力学

行为发生后，下一时刻的内部状态取值为 $\mathbf s'$ 的条件概率写成：

$$
\boxed{
\Pr(\mathbf S_{t+1}=\mathbf s'\mid\mathbf S_t,\mathbf A_t,\mathbf E_t)
=q_t(\mathbf s'\mid\mathbf S_t,\mathbf A_t,\mathbf E_t)
}
$$

这里将当前行为 $\mathbf A_t$ 显式列为条件，表示状态更新不仅与当前内部状态和外界条件有关，也与本人采取的行为有关。例如，练习会影响下一时刻的技能、记忆和身体状态。

与行为生成的表示一致，这里要求当前状态、行为和外界条件包含历史中与下一状态生成有关的全部信息。对每一组给定的条件，各可能下一状态的概率非负，且总和为 $1$；如果某个下一状态的条件概率为 $1$，就包含了确定性更新的情况。

行为生成与状态更新共同表达：当前状态参与生成行为，行为又参与塑造下一状态；下一状态再与下一时刻的外界条件一起参与生成后续行为。

### 4. 总结

结合初始条件与逐步生成过程，一个人任意时刻的行为，最终都完全取决于对他而言的运气。所谓的选择与努力也包含在这一形成过程中。问题就是，一个人一切选择和努力取决于对本人而言的运气，那这个所谓的选择和努力不都是自我安慰吗？

## 论证解释

### 1. 最初的我，不是我选择的

一个人不能选择自己的基因、出生年代、家庭和最初的成长环境，也不能先选择一套性格、欲望和判断能力，再开始人生。

从受精卵到婴儿出生，其初始状态和发育条件未经本人选择，发育所遵循的自然规律也未经本人制定。即使这些过程具有确定的生物学解释，由此获得的先天优势也不能记作本人选择或努力的成果。

因此，在任何能够称为“本人选择”的行为出现之前，用来产生这个选择的身体、能力和已有经历，都已有其形成来源，可以追溯到对本人而言的运气。

### 2. 后来的选择，也不能成为一个独立的起点

**人在这一刻的选择或努力，由此前自身状态与所处条件的完整集合，以及可能参与其中的随机过程共同产生。即使先前状态和规律完全相同，随机过程也可能产生不同结果。**

这不需要额外假定随机性不存在。**即便存在上述随机过程，其具体结果也不由本人掌控，仍然属于前面定义的运气。**

从初始状态开始逐步递推：此前状态在自然规律下，结合相关外部条件和可能参与的随机因素，生成下一时刻的状态与动作；新状态继续参与后续生成过程。具体函数的形式，以及人是否已经研究清楚其机制，不影响这一追溯结构。后来出现的记忆、判断、选择和努力，同样需要说明其生成来源。

对于任何一次选择，都可以追问：为什么这个人会这样选？

- 如果因为他的性格、知识、欲望或判断力，就继续追问这些条件是怎样形成的。
- 如果因为他之前主动改变过自己，就继续追问：他当时为什么想改变，又为什么有能力改变？
- 如果因为某个随机因素，那么随机发生也不等于由本人自主掌控。

“我通过过去的选择塑造了现在的自己”可以是真的，但它不能终止追问，因为过去的选择也需要同样的解释。沿着这条链向前追溯，仍然会回到未经本人选择的起始条件、后续遭遇，以及可能参与其中的随机过程。因此，在这一因果解释下，选择找不到一个最终由本人独立创造的来源；加入随机性也不会产生这样的来源。

所以，不存在一个仅仅因为年龄到了五岁、六岁或十二岁，就让选择突然摆脱其形成条件的时刻。自主能力可以逐渐发展，但能力的发展本身也有来处。

### 3. 用平行宇宙实验检验“努力”的来源

假设一个人早期受到鼓励，逐渐学会规划和练习，最后掌握了一项技能。我们从他受到鼓励的前一秒分出两个世界：一个世界里他受到鼓励，另一个世界里没有。

如果没有鼓励，他就没有学会，那么这次未经他选择的鼓励，就是这条成功路径中的必要条件。

如果没有鼓励，他仍然学会了，也不能据此证明他摆脱了运气。他可能因为兴趣、模仿、其他人的支持或谋生需要而练习。我们可以继续追问这些动机和能力的来源，包括基因、经历，以及此前的选择。

这个实验不是说“只要取消一次鼓励，他就一定失败”，也不是说有限次实验足以证明所有人的所有成功。它说明的是：**找到一条替代的成功路径，并不等于找到了一个最终由本人创造的起点。** 一般性的结论来自上一节的因果追溯，这个实验是对该过程的具体说明。

### 4. 努力是原因，不代表努力独立于运气

一种常见反驳是：“但他确实练习了；不练习，就掌握不了技能。所以不能全归于运气。”

这个反驳回答了“技能是怎样获得的”，却没有回答“他为什么会成为一个愿意并且能够练习的人”。两者可以同时成立：练习造成了技能的提升，而练习的发生及其效果，又依赖于未经本人最终选择的条件。

可以把其中一条因果路径写成：

> 未经选择的条件与遭遇 → 能力、性格和动机 → 选择与努力 → 结果

实际过程还会不断受到新环境和新遭遇的影响，选择也会反过来改变环境。但这种反馈，并不让整条过程获得一个由本人从零创造的起点。

因此，运气、天赋、选择和努力不是四份互不重叠的贡献。天赋可以是运气的一部分，选择和努力可以是这些条件影响结果的途径。承认努力有因果作用，并没有反驳它的来源也可追溯到运气。

### 5. “100% 运气”到底是什么意思？

这里的“100%”不是一个统计测量，也不是说“运气占100%，努力占0%”。它表达的是：**追溯到最终来源，没有留下任何一部分，是由本人在不依赖未经选择的条件的情况下，独立创造出来的。**

于是，论证可以归纳为：

1. 最初的自己和所处条件，不是本人选择的。
2. 后来的选择和努力，由此前自身状态与所处条件的完整集合，以及可能参与其中的随机过程共同产生。
3. 此前的选择也遵循同样的解释，不能仅凭“这是我的选择”就停止追溯。
4. 即使相同条件下可能出现不同的随机结果，这些结果也不由本人掌控，仍然属于运气。
5. 因而，在上述前提下，人不是自身的最终创造者；成功也没有一个最终完全由本人奠定的来源。
6. 因而，一个人的任何行为及其成功，最终都完全取决于对他而言的运气。这里沿用开头对来源的定义，无须增加“及其影响”来把行为和结果归入运气。

这个推导采用的生成原则是：此前状态、相关外部条件、自然规律及可能参与的随机因素，穷尽每一步状态和行为的生成来源。上面的概率公式用于表示这一过程，单靠公式本身不能证明来源的穷尽性。推导不需要额外假定“没有随机性”或“人没有选择能力”，也没有把结论预先放进前提。仅仅指出“人确实会思考、会选择、会努力”，不能终止对这些能力及其运用过程的来源的追问。
